## Задание

- **task-1. Сумма квадратов.** Дано натуральное число `n`. Найти сумму квадратов первых `n` натуральных чисел: 1² + 2² + … + n². Условие и примеры в [task-1/README.md](task-1/README.md).

## Что должно быть в репозитории

В папке `task-1`:

- `Program.cs` и `task-1.csproj` — программа, которая собирается командой `dotnet run`;
- `README.md` — словесный алгоритм, блок-схема и таблица проверки;
- `scheme.png` — блок-схема по ГОСТ 19.701-90.

Папки `bin/` и `obj/` не коммитить, их уже исключает `.gitignore`.

## Как сдать

1. Один человек из команды делает **Fork** этого репозитория и добавляет второго в Collaborators (Settings → Collaborators).
2. Оба клонируют форк, решают задачу и делают commit и push. Коммитить должны оба.
3. Каждый из команды прикрепляет в Google Classroom:
   - ссылку на форк (`https://github.com/<ник>/p42-02-sum-of-squares`);
   - скриншот работы программы.
4. Нажмите «Сдать» до конца пары.
