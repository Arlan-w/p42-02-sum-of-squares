# Задача 1. Сумма квадратов

## Условие

Дано натуральное число `n` (n ≥ 1). Найдите сумму квадратов первых `n` натуральных чисел:

S = 1² + 2² + 3² + … + n²

Программа читает `n` с клавиатуры и выводит сумму.

### Примеры

| Ввод | Вывод | Пояснение |
|---|---|---|
| 2 | 5 | 1² + 2² = 1 + 4 = 5 |
| 8 | 204 | 1² + 2² + 3² + 4² + 5² + 6² + 7² + 8² = 204 |

## Словесный алгоритм

1. 
2. 
3.
